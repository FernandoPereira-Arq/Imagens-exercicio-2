# Página HTML — antes e depois

A página de apresentação do exercício foi preparada nesta conversa como um único ficheiro **index.html**, com imagens, estilos e interatividade incorporados. O ficheiro HTML completo deve ser descarregado da conversa e carregado **nesta pasta docs**. Esta nota não é a página final.

## Conteúdo preparado

- Lisboa: esquiço observado e imagem realista.
- Paris: imagem de modelo digital e imagem realista.
- Aroeira: render de partida e sete resultados sucessivos — materialidade, cobre/telha, blue hour, espreguiçadeiras, vista aérea, revisão pedida com PDF e lado oposto.
- Comparadores antes/depois, vista lado a lado, ampliação das imagens e prompts originais.
- Explicação do pedido, alteração observada e leitura crítica de cada resultado.
- Registo da pesquisa exploratória e dos pedidos posteriores de modelação, distinguindo o modelo simplificado das imagens geradas.

## Carregar a página

1. Descarregar **index.html** da conversa e abri-lo no browser para rever o conteúdo.
2. No GitHub, entrar na pasta **docs** deste repositório.
3. Selecionar **Add file → Upload files**, escolher **index.html** e confirmar o commit na branch **main**.
4. Não carregar um ZIP como página. Não é necessário carregar as imagens em separado na versão de ficheiro único.

## Ativar GitHub Pages

Depois de carregar o HTML: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /docs → Save**.

O repositório permanece privado. A ativação de Pages e a alteração de visibilidade não foram efetuadas nesta preparação.

**Privacidade:** GitHub Free exige um repositório público para Pages. GitHub Pro permite usar um repositório privado como origem, mas a página publicada continua normalmente acessível ao público. Não tornar este repositório público sem rever também os ficheiros e o histórico já existentes. Para publicação gratuita, considerar um novo repositório público contendo apenas o HTML revisto.
